# NEON MIDNIGHT — 야간 도시 아케이드 드리프트

"새벽 2시, 야간 고속도로를 달리는 그 느낌." 신스웨이브(핑크/시안/보라) 야간 팔레트의
웹 기반 레이싱 게임 프로토타입. 3대 핵심 요소 중 **속도감 연출이 주인공**.

순수 웹 기술(HTML + JavaScript + Three.js)만 사용. 외부 에셋(텍스처/모델/오디오 파일) 없음 —
모든 그래픽은 코드 생성(캔버스 텍스처/지오메트리), 모든 사운드는 WebAudio 절차 합성.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다 (file:// 더블클릭 실행 지원, ES 모듈 미사용).
로컬 서버 사용 시: `python3 -m http.server` 후 `http://localhost:8000` 접속.

- Three.js: `three@0.158.0` min 빌드 (jsdelivr CDN, 고정 버전, non-module 전역 `THREE`).
  CDN 실패 시 cdnjs `0.149.0`으로 자동 폴백합니다. 오프라인에서는 최초 로드가 필요합니다.

## 조작법

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크 / 후진 |
| A·D / ←·→ | 조향 |
| Space | 핸드브레이크 (드리프트 강제 진입) |
| Shift | 부스트 (게이지 충전 시) |
| R | 리스타트 |
| M | 음소거 |

## 게임 규칙

- 드리프트를 지속하면 점수가 모이고, 드리프트가 끝날 때 체인 × 지속시간 배율로 확정됩니다.
- 확정된 점수는 부스트 게이지를 충전하고, 가득 차면 Shift로 부스트(최고속 + 가속 향상) 사용 가능.
- 가드레일 충돌 시 반사 + 감속, 드리프트 체인에 페널티.
- 트랙 1바퀴 = 1랩 (목표 40~60초), 랩타임/베스트 랩 기록.

## 파일 구성

| 파일 | 역할 |

| `track.js` | 트랙 중심선(Catmull-Rom 폐곡선), 노면/가드레일 리본 지오메트리, 위치 조회·충돌 좌표 |
| `decor.js` | 가로등, 네온 간판 게이트, 건물 실루엣, 터널(벽/천장/네온 링), 고가교 기둥, 스카이라인, 지면 그리드, 별 |
| `physics.js` | 아케이드 드리프트 물리 (그립↔슬립, 핸드브레이크, 부스트, 가드레일 반사) |

| `main.js` | 초기화, 입력, 게임 루프, 랩 판정, 드리프트 채점, 리스타트 |

## 구현 특징

### 1. 드리프트 물리 (아케이드)
- 차량 속도를 차체 기준 전방(vF)/측면(vL) 성분으로 분해. 측면 성분의 감쇠 계수(latK)를
  상태에 따라 바꾸는 방식으로 그립(9.5/s)↔미끄러짐(1.7/s) 경계를 일부러 넓게 잡았습니다.
- 슬립각 `atan2(vL, |vF|)` 기반 히스테리시스 상태 머신: |슬립| > 0.30 rad에서 진입,
  < 0.13 rad로 복귀 + 핸드브레이크 강제 진입(속도 8 m/s 이상).
- 드리프트 중에는 조향 권한이 커지고(요우 계수 1.9) 스로틀에 측면 킥이 붙어 슬라이드 유지가 쉬움.
  저속에서는 요우가 차단되어 제자리 회전이 불가능, 고속일수록 조향이 둔해짐(속도 감쇠).
- 가드레일: 중심선 횡오프셋 판정 → 안쪽으로 위치 보정, 측면 속도 반발계수 0.42 반사,
  접촉 중 종방향은 초당 지수감쇠(프레임률 무관), 충격량은 셰이크/사운드/플래시로 피드백.
- 120 Hz 고정 서브스텝 적립 방식이라 프레임률과 무관하게 동일한 물리.

### 2. 트랙 (밤 도시 서킷, 연장 약 1.85 km)
- 16개 제어점의 closed Catmull-Rom → 720 등간격 샘플(위치/접선/측면/부호 곡률/누적거리).
- 리듬 배치: 시작 고속 직선 → 광폭 드리프트 코너(반경 큼) → 고속 S자 → 상승하며 고가도로화
  (최고 고도 12 m, 지하 기둥 자동 생성) → 고가 직선 → 우측 곡선 강하 → 터널 구간(네온 링) → 복귀.
- 노면은 캔버스 텍스처(아스팔트 스펙클 + 노측 실선 + 차선 점선 + 시안 중앙 점선)를 18 m 타일로 반복.
- 가드레일 발광 스트립은 곡률에 따라 색이 바뀌는 정점 컬러(직선 시안 / 급코너 핑크).
- 충돌 조회는 이전 샘플 인덱스를 힌트로 ±50 샘플 윈도 탐색(상수 시간), 이탈 시에만 전역 탐색.
- 주변 소품: 30 m 간격 가로등(전구 글로우 + 노면 라이트 풀), 130 m 간격 네온 간판 게이트,
  랜덤 배치 창문 발광 건물 150동(도로 34 m 이격 보장), 터널, 스타트 게이트.
  대부분 InstancedMesh로 묶어 드로우콜 최소화.

### 3. 속도감 연출 (최우선 — 이 게임의 주인공)
- **라이트 스트리밍**: 터널 네온 링(시안/핑크 교대, 9 m 간격), 가로등·간판·가드레일 스트립이
  리듬감 있게 스쳐 지나가고, 속도 28% 초과부터 스피드 스트릭(도로 양옆을 통과하는
  인스턴스 광 스트립 46개)이 출현 — 속도에 비례해 스트립 길이가 늘어나 모션블러 느낌.
- **속도 비례 FOV**: 63° 기준 → 속도 비례 최대 +30°, 부스트 중 +8°, 드리프트 중 +3° (스무딩).
- **라이트 트레일**: 드리프트 중 후륜에서 시안(좌)/핑크(우) 발광 리본이 이어지고
  정점 알파로 페이드아웃 (차대당 최대 80세그먼트).
- **안개/깊이감**: 보라빛 Fog — 속도가 붙으면 시야가 멀어지고(far 400→560), 터널에서는
  밀착(near 7/far 150)으로 압축감. 지평선 핑크 글로우 스카이라인 + 별 700개.
- **카메라**: 속도에 따라 후방 거리·높이가 늘어나는 추격 카메라, 드리프트 시 슬립 방향으로
  측면 오프셋, 속도² 기반 미세 진동 + trauma 기반 충격 셰이크(임팩트 시 강하게).
- **DOM 포스트 이펙트**: 속도/부스트에 반응하는 보라 스피드글로우, 비네트 강화, 충돌 플래시,
  스캔라인 오버레이.
- 색감: 배경 #07030f, 핑크 #ff2d95 / 시안 #00e5ff / 보라 #7b2dff / 골드 #ffd166.

### 4. 사운드 (WebAudio 절차 생성, 외부 파일 없음)
- 엔진: saw + square(2옥타브) 오실레이터 → 로우패스. 6단 기어 속도 구간별로 RPM이
  올라가는 피치 패턴(46 Hz~) + 스로틀 로드에 따른 필터 개방과 게인.
- 타이어 스핀: 화이트노이즈 → 밴드패스(760 Hz) 게인 = 휠스핀 × 속도 비례.
- 바람: 노이즈 → 로우패스, 속도² 비례. 터널 진입 시 피드백 딜레이 에코 웨트 인.
- 원샷: 충돌(트라이앵글 피치드랍 + 금속성 노이즈 버스트), 부스트(상승 스윕), 랩 완료(4음 아르페지오).
- AudioContext는 첫 키 입력(사용자 제스처) 시 생성.

## 검증

- 모든 JS 파일 `node --check` 통과 (node v22.22.2).
- 헤드리스 Chrome(신스웨이브 소프트웨어 WebGL) 런타임 테스트: 로드/주행/드리프트 채점/HUD/
  터널·고가 구간 렌더링 확인, 콘솔 에러 0. 스크린샷으로 노면·네온 링·건물·가드레일 스트립 확인.
  테스트 후 임시 파일은 삭제했습니다.

## 알려진 한계

- 브라우저 자동 테스트 환경(헤드리스 + 소프트웨어 렌더러)의 특성상 rAF 프레임 수가 제한되어,
  **부스트 사용(Shift)과 랩 완주 전체 사이클은 자동 검증하지 못하고 코드 리뷰로 확인**했습니다.
  사운드 출력도 헤드리스에서 청취 검증은 불가합니다(코드 경로 오류 없음은 확인).
- CDN에서 Three.js를 로드하므로 최초 1회는 네트워크가 필요합니다 (완전 오프라인 미지원).
- 물리는 단순 2D 자전거 모델 기반의 아케이드 근사이며, 타이어 슬립 비율/하중이동은
  실제 차량 동역학이 아닙니다 (본 컨셉의 의도).
- 충돌은 가드레일(중심선 기반)만 지원 — 트랙 이탈은 구조상 불가능.
- 고드로우콜 최적화(프러스텀 컬링 등)는 인스턴싱 수준까지만 적용.
- 디버그 훅: 콘솔에서 `NM_DEBUG.teleport(0~1)`로 트랙 임의 지점 순간이동 가능.
